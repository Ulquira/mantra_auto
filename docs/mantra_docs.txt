Gestión de contactos 
Creación y Actualización de contacto 
Para crear o actualizar un contacto dentro de un grupo se utiliza su número telefónico (campos 
countryCode y phone) para verificar si está registrado o no: 
• Si no hay un contacto asociado con el número telefónico especificado entonces se crea un 
nuevo contacto con los datos 
• Si ya existe un contacto asociado con el número telefónico especificado, se procede a 
actualizar ese contacto con los nuevos datos 
Request 
URL https://wbpback.mantra.chat/contacts/new 
HTTP Method POST 
Headers Content-Type: application/json 
Parámetros: 
Nombre Tipo Descripción 
groupId string Dato de autentificación de cuenta Mantra 
apiKey string Dato de autentificación de cuenta Mantra 
data object Objeto que contiene datos del contacto a crear o actualizar 
data.name string Nombre completo 
data.phone string Número telefónico que se usará para interactuar por Whatsapp 
No debe incluir el código de país 
data.countryCode string Código de país del número telefónico 
data.email string Correo electrónico (opcional) 
data.custom_1 string 
Sirve para guardar cualquier dato que luego puede ser usado en 
plantillas 
Son 10 campos disponibles desde custom_1 a custom_10 
(opcionales) 
data.tagIds array 
ID de la etiqueta o etiquetas que se asociarán al contacto 
(opcional) 
Si el contacto ya existe este se asocia con las etiquetas 
especificadas sin alterar las que ya tenía asociadas 
El ID de la etiqueta se obtiene al crear la etiqueta usando el 
Endpoint de Creación Etiqueta 
Request body: 
{ 
  "groupId":"GROUP_ID", 
  "apiKey":"GROUP_API_KEY", 
  "data": { 
    "name": "Contact 1", 
    "phone": "911000001", 
    "countryCode": "51", 
    "email": "contact1@mantra.chat", 
    "custom_1": "Dato personalizado 1", 
    "tagIds": ["TAG2_ID","TAG3_ID"] 
  } 
}  
Response 
Response body: 
{ 
  "name": "Contact 1", 
  "phone": "911000011", 
  "email": "contact1@mantra.chat", 
  "custom_1": "Dato personalizado 1", 
  "tagIdList": ["TAG1_ID","TAG2_ID","TAG3_ID"], 
  "resultOp": "created" 
} 
Status codes: 
• 201 Created, si el contacto fue creado 
• 200 OK, si el contacto fue actualizado 
• 400 Bad Request, si los parámetros enviados están incorrectos o faltan 
• 403 Forbidden, si las credenciales (campos groupId ó apiKey) son incorrectas 
• 500 Internal Server Error, si hubo algún error interno durante la ejecución de la 
operación 
 
 
 
Asociación de usuario y contacto 
Para asociar un contacto a un usuario, utilizando el e-mail del usuario (campo userEmail) y 
número telefónico del contacto (campos countryCode y phone), considerando lo siguiente 
dentro de un grupo: 
• Si ya está registrado un contacto con el número telefónico especificado, se procede a 
actualizar ese contacto con los nuevos datos 
• Si además ese contacto ya estaba asociado a otro usuario, se procede a asociar con el 
usuario correspondiente al e-mail especificado 
Request 
URL  https://wbpback.mantra.chat/contacts/newbyuser 
HTTP Method POST  
 Headers Content-Type: application/json 
Parámetros: 
Nombre Tipo Descripción 
groupId string Dato de autentificación de cuenta Mantra 
apiKey string Dato de autentificación de cuenta Mantra 
userEmail string E-mail de agente que está registrado en la cuenta Mantra y con el 
cual se asociará el contacto 
data object Objeto que contiene datos del contacto a crear o actualizar 
data.name string Nombre completo 
data.phone string Número telefónico que se usará para interactuar por Whatsapp 
No debe incluir el código de país 
data.countryCode string Código de país del número telefónico 
data.email string Correo electrónico (opcional) 
data.custom_1 string 
Sirve para guardar cualquier dato que luego puede ser usado en 
plantillas 
Son 10 campos disponibles desde custom_1 a custom_10 
(opcionales) 
data.tagIds array 
ID de la etiqueta o etiquetas que se asociarán al contacto 
(opcional) 
Si el contacto ya existe este se asocia con las etiquetas 
especificadas sin alterar las que ya tenía asociadas 
El ID de la etiqueta se obtiene al crear la etiqueta usando el 
Endpoint de Creación Etiqueta 
createdByBot string Parte final del webhook si el endpoint es usado por un bot 
Request body: 
{ 
  "groupId":"GROUP_ID", 
  "apiKey":"GROUP_API_KEY", 
  "userEmail":"publisher@aryadev.pe", 
  "data": { 
    "name": "Contact 1", 
    "phone": "911000001", 
    "countryCode": "51", 
    "email": "contact1@mantra.chat", 
    "custom_1": "Dato personalizado", 
    "tagIds": ["TAG2_ID","TAG3_ID"] 
  }, 
  "createdByBot": "BOT_ID" 
}  
Response 
Response body: 
{ 
  "name": "Contact 1", 
  "phone": "911000001", 
  "countryCode": "51", 
  "email": "contact1@mantra.chat", 
  "custom_1": "Dato personalizado", 
  "tagIdList": ["TAG1_ID","TAG2_ID","TAG3_ID"], 
  "resultOp": "created" // "updated" - si el contacto ya estaba registrado 
} 
Status codes: 
• 201 Created, si el contacto fue creado 
• 200 OK, si el contacto fue actualizado 
• 400 Bad Request, si los parámetros enviados están incorrectos o faltan 
• 403 Forbidden, si las credenciales (campos groupId ó apiKey) son incorrectas 
• 409 Conflict, cuando el usuario correspondiente al campo userEmail no es agente 
• 500 Internal Server Error, si hubo algún error interno durante la ejecución de la 
operación

Creación de Etiqueta 
Para crear una etiqueta dentro de un grupo se verifica si el nombre (campo name) ya está 
registrado: 
• Si no existe una etiqueta con el nombre entonces se crea y se devuelve su ID con el 
estado created 
• Si ya existe una etiqueta con el nombre entonces sólo se devuelve su ID con estado found 
Request 
URL https://wbpback.mantra.chat/contacts/new-tag 
HTTP Method POST 
Headers Content-Type: application/json 
Request body: 
{ 
  "groupId":"GROUP_ID", 
  "apiKey":"GROUP_API_KEY", 
  "name":"Etiqueta de prueba" 
}  
Response 
Response body: 
{ 
  "id": "TAG_ID", 
  "status": "created" // "found" - si la etiqueta ya existía 
} 
Status codes: 
• 200 OK, si la etiqueta fue creada o si ya existía una etiqueta con el nombre 
• 400 Bad Request, si los parámetros enviados están incorrectos o faltan 
• 500 Internal Server Error, si hubo algún error interno durante la ejecución de la 
operación 
Envío de plantillas 
Envío de una plantilla a un contacto 
Para enviar una plantilla a un contacto, se necesita especificar el ID de la plantilla (atributo 
templateId) y el número telefónico del contacto (campos countryCode y phone). 
Request 
URL https://wbpback.mantra.chat/contacts/send 
HTTP Method POST 
Headers Content-Type: application/json 
Parámetros: 
Nombre Tipo Descripción 
groupId string Dato de autentificación de cuenta Mantra 
apiKey string Dato de autentificación de cuenta Mantra 
templateId string ID de plantilla registrada en cuenta Mantra 
phone string Número telefónico de contacto registrado en cuenta Mantra 
No debe incluir código de país 
countryCode string Código de país del número telefónico 
sendByBot string Parte final del webhook si el endpoint es usado por un bot 
Request body: 
{ 
  "groupId": "GROUP_ID", 
  "apiKey": "GROUP_API_KEY", 
  "templateId": "TEMPLATE_ID",   
  "phone": "911000001", 
  "countryCode": "51" 
  "sendByBot": "BOT_ID", 
} 
Response 
Response body: 
{ 
  "ok": true 
} 
Status codes: 
• 201 Created, si la orden de enviar la plantilla fue realizada con éxito 
• 400 Bad Request, si los parámetros enviados están incorrectos o faltan 
• 403 Forbidden, si las credenciales (campos groupId ó apiKey) son incorrectas 
• 404 Not Found, si no hay registro de contacto asociado al número telefónico o no hay 
registro de plantilla asociada al ID de plantilla 
• 406 Not Acceptable, si la operación no puede realizarse (ejemplo cuota de envíos de 
plantilla fue excedida) 
• 500 Internal Server Error, si hubo algún error interno durante la ejecución de la 
operación 
Bots 
Consultar reporte de bots/flows 
Para consultar los datos guardados del bot/flow pertenecientes a un grupo especificado. 
Request 
URL https://wbpback.mantra.chat/bots/data-report 
HTTP Method POST 
Headers Content-Type: application/json 
Parámetros: 
Nombre Tipo Descripción 
groupId string Dato de autentificación de cuenta Mantra 
apiKey string Dato de autentificación de cuenta Mantra 
botId string ID de bot o flow registrado en el reporte de una cuenta Mantra 
limit string Número de registros obtenidos por página. Acepta valores desde 10 a 1000. 
page string Número de página. Acepta valores mayores que 1. 
fromDate string Fecha desde donde se obtendrán los datos (opcional) . Debe ser de la forma 
“YYYY-MM-DD“ 
toDate string Fecha hasta donde se obtendrán los datos (opcional) . Debe ser de la forma 
“YYYY-MM-DD“ 
Request body: 
{ 
  "groupId": "GROUP_ID", 
  "apiKey": "GROUP_API_KEY", 
  "botId": "BOT_ID/FLOW_ID",   
  "limit": "10", 
  "page": "1" 
  "fromDate": "2023-05-05", 
  "toDate": "2024-03-15" 
} 
Response 
Response body: 
{ 
 "total": 1, 
 "page": 1, 
 "totalPages": 1, 
 "data": [ 
  { 
   "Nombre": "Test Mantra", 
   "Celular": "+51999999999", 
   "Fecha": "2024-7-9", 
   "Hora": "6:42:38", 
   "Estado": "status_50", 
   "Proyecto": "Test Project" 
  } 
 ] 
} 
Status codes: 
• 200 OK, si los datos se obtuvieron con éxito. En el caso de que no haya datos disponibles 
se retorna un array vacío. 
• 400 Bad Request, si los parámetros enviados están incorrectos o faltan 
• 401 Unauthorized, si la apiKey no es válida. 
• 404 Not Found, si no hay registro del grupo. 
• 500 Internal Server Error, si hubo algún error interno durante la ejecución de la 
operación 
 
Historial de mensajes de contacto 
Consultar historial de mensajes de chat 
Para obtener el historial completo de mensajes entre un contacto específico y los agentes 
asignados. 
Request 
URL https://wbpback.mantra.chat/contacts/chats/historial 
HTTP Method POST 
Headers 
Authorization: Bearer <apiKey> 
GroupId: <groupId> 
Content-Type: application/json 
Parámetros: 
Nombre Tipo Descripción 
countryCode string Código de país del número de teléfono 
phone string Número de teléfono sin código de país 
page number Número de página. Acepta valores mayores o iguales a 1. Valor por 
defecto: 1 
limit number Número de registros por página. Acepta valores desde 1 a 100. Valor 
por defecto: 50 
Request body: 
{ 
    "countryCode": "56", 
    "phone": "987987987",  
    "page": 1, 
    "limit": 10 
} 
Response 
Response body: 
{ 
    "data": [ 
        ..., 
        { 
            "agent": { 
                "name": "John Doe",

                "assignedByUserName": "", 
                "assignedByBotId": "{{BOT_ID}}}", 
                "unassignedAt": "", 
                "unassignedBy": "", 
                "unassignedByUserName": "" 
            }, 
            "content": { 
                "type": "text", 
                "text": "¡Hola! Quiero cotizar...", 
                "media": "" 
            }, 
            "sender": "contact", 
            "status": "received", 
            "createdAt": "2025-01-11T13:21:52.664Z", 
            "updatedAt": "2025-01-11T13:21:52.664Z", 
            "sentByUser": { 
                "name": "John Doe", 
                "email": "john.doe@acme.com", 
                "type": "publisher" 
            } 
        }, 
        ...         
    ], 
    "total": 35, 
    "totalPages": 4, 
    "page": 1, 
    "limit": 10 
} 
Status codes: 
• 200 OK, si los datos se obtuvieron con éxito. 
• 400 Bad Request, si los parámetros limit (1-100) y page (≥1) no son números válidos 
• 401 Unauthorized, si falta el header Authorization, falta el header GroupId, o las 
credenciales son incorrectas 
• 404 Not Found, si no se encuentra el contacto especificado o no se encontraron 
mensajes para este contacto 
• 500 Internal Server Error, si hubo algún error interno durante la ejecución de la 
operación 
Tipos de mensaje (content.type): 
• text - Mensaje de texto simple 
• quick_reply - Mensaje con botones de respuesta rápida 
• button_reply - Respuesta de botón seleccionado 
• media - Mensaje con archivo multimedia 
Tipos de remitente (sender): 
• contact - Mensaje enviado por el cliente 
• group - Mensaje enviado por agente/empresa 
Estados de mensaje (status): 
• received - Mensaje recibido 
• read - Mensaje leído 
• delivered - Mensaje entregado
